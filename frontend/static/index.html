How the question was routed
Structured data: NASA Exoplanet Archive, PSCompPars table — downloaded directly via NASA's public TAP API. 6,298 confirmed planets across 4,716 host stars, in a real two-table PostgreSQL schema.

Conceptual knowledge: 18 Wikipedia articles on detection methods and astronomy concepts, retrieved via hybrid search — lexical (full-text) and semantic (vector embeddings) search combined with Reciprocal Rank Fusion, not just one or the other.

How answers are derived: a planner first decides whether a question needs the database, retrieval, or both — splitting it into separate sub-questions if it asks for genuinely unrelated things. Every number comes from a real SQL row; every concept comes from a cited passage. Neither comes from the model's own memory. View the source & full findings log →
